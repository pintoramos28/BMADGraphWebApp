- `src/features/import/workspace-import-route.tsx`: `handleFileImport()` still reads the entire file on the main thread with `await file.text()` / `await file.arrayBuffer()` before `beginImport()` sets parsing state or starts the budget timer. A large local file can therefore leave the UI looking idle with no in-progress feedback, which misses the story’s requirement to show visible progress once preview readiness exceeds the target.

- `src/services/persistence/fs-access/local-import-files.ts`: the cancellation fix only covers `showOpenFilePicker()`. The hidden-input fallback still resolves only from a `change` listener, so canceling that picker never settles the promise. On browsers using the fallback path, the import action can still hang indefinitely after cancel instead of behaving like the new no-op contract.

- `src/features/import/workspace-import-route.tsx`: dropping stale worker messages does not cancel the stale parse itself. Because the component keeps one long-lived worker instance, an abandoned slow import can continue consuming the worker and delay the user’s replacement import even though its messages are ignored. This fixes state corruption, not the underlying responsiveness problem.

- `src/features/import/store.ts`: the stale-message guard is optional at the API boundary because `updateProgress`, `resolveImport`, and `failImport` all accept `correlationId?: string`. Any future caller can omit the id and bypass the protection entirely without a type error, making the regression easy to reintroduce.

- `tests/e2e/import.spec.ts` and `src/features/import/store.spec.ts`: the added coverage does not prove the riskiest behaviors in this patch. There is still no route-level test that a slow import shows progress once the budget is exceeded, no browser-level test that stale worker replies are ignored after a newer import starts, and no fallback-file-input cancellation test even though Playwright now forces that path.

- `src/types/papaparse.d.ts`: the new local type shim is narrower than the story contract and the stated library usage. It only models string parsing with a minimal config, omitting file input, callbacks, preview mode, and worker mode. This “fix” hard-codes the current limited usage and creates a new maintenance trap the moment the implementation tries to use Papa Parse features the story explicitly calls for.
