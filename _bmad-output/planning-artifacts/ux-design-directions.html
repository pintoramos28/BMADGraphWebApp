BMADGraphWebApp – Design Directions

Six visual explorations built on the Mission Control palette, responsive grid, and graph-first workflows.

Direction 1

Mission Control Focus

Dark mission rail with luminous telemetry chips. Graph canvas dominates the center, with evidence rail pinned right. Status badges glow teal/amber.

  • For Priya’s investigative flow
  • High-density data with collapsible panes
  • Offline state showcased via toolbar chips
Direction 2

Calm Analyst

Light chrome everywhere. Graph templates presented as cards left of canvas. Great for David’s “better Excel” expectation with strong helper copy.

  • Hero onboarding with sample data
  • Semantic chips highlighted in indigo
  • Evidence rail hidden by default
Direction 3

Split Horizon

Dual-column layout: left for graph builder + telemetry, right for mission log + reviewer notes. Favors Elena’s need for provenance.

  • Ledger cards reuse JetBrains Mono
  • Graph canvas remains 16:9 even when resized
  • Great for multi-monitor analysts
Direction 4

Telemetry Stream

Vertical telemetry spine overlays the canvas edge, pulsing with real-time status. Ideal when offline/queue transparency is paramount.

  • Statuses stacked chronologically
  • Graph editing toolbar floats bottom-center
  • Great for operations reviews
Direction 5

Template Gallery

Homepage emphasizes reusable graph templates with big previews. Once selected, the canvas converts to Mission Control Focus styling.

  • Grid of template cards
  • Walkthrough copy for David
  • Stats on SLA (≤1s edit, ≤2s transform)
Direction 6

Reviewer Dock

Evidence rail expands into a timeline when reviewers join. Elena gets inline approvals, drift alerts, and attachment slots.

  • Timeline uses saffron/crimson for drift/error
  • Reviewer avatars pinned to ledger entries
  • Graph thumbnails display side-by-side diffs

Evaluation Lens

Layout Intuitiveness
Mission Control Focus & Split Horizon keep graph central while giving telemetry persistence.
Interaction Style
Calm Analyst + Template Gallery emphasize guidance; Telemetry Stream highlights live state.
Visual Weight
Dark rails contrast crisp canvases in Mission Control Focus; Calm Analyst stays airy.
Navigation & Density
Template Gallery uses cards; Reviewer Dock prioritizes timeline navigation for QA sign-off.
