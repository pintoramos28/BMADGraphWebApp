BMADGraphWebApp – Simple vs Advanced Modes per Direction

Each direction includes David's calm graphing mode and Priya's advanced analysis mode to illustrate how the shell adapts without losing cohesion.

Direction 1 · Mission Control Focus

Simple Mode “Ready for offline use” · teal chip
Guided scatter template · helper copy
Semantic chips auto-suggest roles; evidence rail tucked; telemetry quiet unless action needed.
Advanced Mode Telemetry: 0.6s edits · 3 queued
Layer stack · dual axes · fit overlay
X: Time Y: Temp Facet: Region Drift: 2%
Docked evidence rail visible; reviewer timeline pinned right; keyboard hints exposed.

Direction 2 · Calm Analyst

Simple Mode Template “Variance vs Time”
Card deck of recommended charts
Large helper text, inline repair cards, “Ready to graph” badge in teal.
Advanced Mode Palette shortcuts · Cmd+K
Side-by-side small multiples + residuals
Derived: TorqueAdj Filter: Range < 50
Dense table toggled below chart; evidence rail collapsible; telemetry badges sit on light chrome.

Direction 3 · Split Horizon

Simple Mode Mission log collapsed
Graph center-left · notes hidden
Mission log panel summarized as a single pill showing latest action.
Advanced Mode Mission log expanded
Graph left · ledger right
JetBrains Mono ledger lists semantic overrides, reviewer approvals, telemetry events in chronological order.

Direction 4 · Telemetry Stream

Simple Mode Telemetry spine minimized
Floating toolbar · minimal alerts
Only “Ready” badge visible; stream auto-hides until a warning occurs.
Advanced Mode Telemetry spine expanded
Live queue · offline sync pulses
Each event card shows latency, queued metrics, and ability to jump to logs; Priya monitors without leaving canvas.

Direction 5 · Template Gallery

Simple Mode “Pick a graph to start”
Template grid + SLA badges
Progress indicators show steps completed; evidence rail absent until later.
Advanced Mode Switch template view
Quick swap between saved templates
Priya stores custom templates; teal badge indicates performance budget compliance, saffron warns when transform >2s.

Direction 6 · Reviewer Dock

Simple Mode Reviewer dock hidden
Graph + single status line
David just sees “Provenance current · 14:05” and a teal confirmation badge.
Advanced Mode Reviewer dock timeline
Timeline cards + diff thumbnails
Timeline uses saffron/crimson for drift/error; avatars show who approved; attachments accessible inline.
