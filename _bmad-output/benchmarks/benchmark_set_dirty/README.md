## Dirty Import Benchmarks

This directory holds the canonical dirty import fixtures for Story 2.2.

- `csv/import.dirty.delimiter-repair.csv` supports the `import.dirty.delimiter-repair` scenario.
- `csv/import.dirty.header-repair.csv` supports the `import.dirty.header-repair` scenario.
- `csv/import.dirty.type-repair.csv` supports the `import.dirty.type-repair` scenario.
- `csv/import.dirty.missing-value-repair.csv` supports the `import.dirty.missing-value-repair` scenario.

Each fixture is paired with a short metadata note describing the ambiguity or data-quality issue the preview must surface before the import can be confirmed.
