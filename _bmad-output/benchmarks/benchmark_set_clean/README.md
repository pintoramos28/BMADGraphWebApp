## Clean Import Benchmarks

This directory holds the canonical clean import fixtures for Story 2.1.

- `csv/import.clean.csv-preview.csv` supports the `import.clean.csv-preview` scenario.
- `excel/import.clean.excel-preview.xlsx` supports the `import.clean.excel-preview` scenario.
- `paste/import.clean.paste-preview.txt` supports the `import.clean.paste-preview` scenario.

Each fixture is paired with a short metadata note describing the source kind, intended scenario, and expected preview behavior.
